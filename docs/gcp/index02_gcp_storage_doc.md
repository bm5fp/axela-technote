# Storage

## Cloud Storage

Cloud Storageは、オブジェクトストレージサービスです。ファイルシステムのような階層構造ではなく、「バケット」と呼ばれる入れ物の中に、キーと値（実体データ）のペアとしてオブジェクトを格納します。

|ストレージクラス|概要|
|---|---|
|Standard|頻繁にアクセスされるデータ向け|
|Nearline|月1回程度のアクセス頻度のデータ向け|
|Coldline|四半期に1回程度のアクセス頻度のデータ向け|
|Archive|年1回程度、長期保管が目的のデータ向け|

|項目|概要|
|---|---|
|ロケーション|単一リージョン、2リージョン、マルチリージョンから選択でき、可用性とレイテンシ、コストのバランスを取る|
|ライフサイクル管理|一定期間経過後に自動的にストレージクラスを移行したり、削除したりするルールを設定できる|
|署名付きURL|一時的にオブジェクトへのアクセス権を第三者に付与するための、有効期限付きURL|

コンテナイメージのレイヤやバックアップデータ、静的ウェブサイトのホスティングなど、非構造化データ全般の保管先として広く使われます。

## Persistent Disk

Persistent Diskは、Compute EngineやGKEのNodeにアタッチして使う、ブロックストレージサービスです。

|種別|概要|
|---|---|
|標準永続ディスク（pd-standard）|HDD相当。低コストだが低速|
|バランス永続ディスク（pd-balanced）|SSD相当のコストパフォーマンスバランス型|
|SSD永続ディスク（pd-ssd）|高いIOPS・スループットが必要なワークロード向け|
|リージョナル永続ディスク|複数ゾーンに同期レプリケーションされ、単一ゾーン障害時にも他ゾーンから継続利用できる|

GKEでは、CSIドライバを通じてこのPersistent DiskがPersistentVolumeとして動的にプロビジョニングされます（Kubernetesドキュメントの[Storage](../kubernetes/index04_k8s_storage_doc.md)を参照）。

## Filestore

Filestoreは、GCPが提供するマネージドNFS（ファイルストレージ）サービスです。

|項目|概要|
|---|---|
|用途|複数のVMやPodから同時に読み書きしたいファイル共有（ReadWriteMany）が必要な場合に使う|
|Persistent Diskとの違い|Persistent Diskは基本的に単一インスタンスからのアタッチ（ReadWriteOnce）が前提だが、FilestoreはNFSプロトコルにより複数クライアントからの同時マウントに対応する|
|階層（ティア）|Basic、Zonal、Enterpriseなど、性能・可用性要件に応じた複数の階層が用意されている|

## サービスの使い分け

|要件|向いているサービス|
|---|---|
|画像・動画・バックアップなど非構造化データの保管、複数リージョンからのアクセス|Cloud Storage|
|VM/Podに直接アタッチする単一ノード向けの高速ディスク|Persistent Disk|
|複数ノードから同時に読み書きする共有ファイルシステムが必要|Filestore|

「オブジェクトとして扱うか（Cloud Storage）」「ブロックデバイスとして扱うか（Persistent Disk）」「ファイルシステムとして扱うか（Filestore）」という抽象化レベルの違いが、サービス選定の基本的な判断軸になります。
